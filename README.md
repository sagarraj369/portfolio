# Sagar M — Portfolio

A responsive Liquid Glass / Glassmorphism portfolio website for Sagar M.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive Liquid Glass styling and animations
- `script.js` — mobile menu, active navigation and footer year

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Customize
Edit the text in `index.html` and the CSS variables at the top of `styles.css` to personalize colors, content and layout.
